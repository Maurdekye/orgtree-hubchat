Hubchat 1.3.5 adds a long-press menu to DMs in the Android chat list.

## Downloads

| File | For |
|---|---|
| `Hubchat_1.3.5_x64-setup.exe` | Windows 10 or 11, 64-bit. The installer is unsigned; SmartScreen may require **More info > Run anyway**. |
| `Hubchat_1.3.5_arm64.apk` | Android 7.0 or later on 64-bit ARM. Allow installation from your browser or file manager when Android asks. |
| `Hubchat-android.apk` | The same Android app under a stable download name. |
| `Hubchat_1.3.5_universal.dmg` | **Prototype** for macOS, Apple Silicon and Intel. Not signed by Apple or notarized. |
| `Hubchat_1.3.5_amd64.AppImage`, `Hubchat_1.3.5_amd64.deb` | **Prototype** for 64-bit Linux. |
| `SHA256SUMS.txt` | SHA-256 checksums for the release files. |
| `latest.json`, the `.sig` files and `Hubchat_1.3.5_universal.app.tar.gz` | Used by Hubchat's built-in updater. |

## Long-press a DM (Android)

- **Long-press a DM in the chat list** to open its menu: **Open**, **Contact info**, **Copy mention** and **Close DM**, the same actions as the desktop chat-list menu. The long-press only opens the menu; a normal tap still opens the chat.
- **Close DM** works as before: it hides the DM on this device only, keeps its history, and a new message reopens it.

## Notes
